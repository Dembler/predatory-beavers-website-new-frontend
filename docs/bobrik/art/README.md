# Единый Бобрик

Две позы одного персонажа, собранные из предоставленных владельцем PNG.
Основной облик взят из варианта с мячом: одинаковые лицо, мех, форма ВГУ,
надписи, номер 100, хвост и красные кроссовки. Различается только рука.

- [Поза с мячом — прозрачный PNG 1024 × 1536](./bobrik-ball.png).
- [Поза с жестом — прозрачный PNG 1024 × 1536](./bobrik-thumbsup.png).
- [Общий просмотр](./bobrik-unified-preview.jpg).
- [Происхождение и описание растрового редактирования](./PROVENANCE.md).

Это обработка готовых иллюстраций. Новая AI-генерация не использовалась:
после ошибки API о нехватке кредитов владелец выбрал работу с исходными PNG.
Веб-файлы и manifest находятся в `public/mascot/bobrik/`. Полноразмерные
мастеры не загружаются виджетом.
