# Исходники шрифтов

TTF и лицензии OFL хранятся здесь, вне публичной сборки. Сайт загружает WOFF2 из `public/fonts/` с кириллицей и исходным диапазоном начертаний.

Для повторной генерации установите `fonttools[woff]` в локальное Python-окружение и запустите `python scripts/optimize_fonts.py` из корня frontend. Лицензии также доступны рядом с публичными шрифтами.
