- Интерактивная схема бросков, викторина, повторное прохождение.
- Миграции, сохранность исходных данных, первый и повторный локальный запуск,
  прозрачность изображений, ограничения multipart и обработка конкурентной загрузки.

## Данные и запуск

CRUD-тесты выполнялись только на `backend/data/e2e.db` с отдельной медиатекой
и проверкой защищённого маркера тестовой среды. Обычный API этот маркер не предоставляет.

Для обычной работы используется игнорируемая Git `backend/data/local.db`:
12 исходных игроков, 13 матчей и локальный администратор. Исходный снимок
`data/predatory_beavers.db` сохранён без добавления локального администратора.
Перед миграцией создаются согласованные SQLite-копии.

Из каталога backend:

```powershell
.venv/Scripts/python.exe scripts/setup_local.py --apply --serve
```

Из каталога frontend:

```powershell
npm.cmd run dev -- --host 127.0.0.1 --configLoader native
```

Сайт: `http://localhost:5173`, админка: `/admin`.
Данные входа находятся только в игнорируемом `backend/data/local-admin-credentials.json`.
Здесь `backend` означает соседний каталог `predatory-beavers-website-new-backend`.
Обычный API запущен на `127.0.0.1:8000`. После переключения с тестовой базы проверены
вход, защищённые списки, выход и отказ 401 после выхода напрямую и через frontend.
Дополнительно на desktop/mobile проверены вход через форму, открытие и закрытие
редактора игрока и выход; записи клуба при этой проверке не изменялись.

## Ограничения проверки

В `npm audit --omit=dev` уязвимостей не найдено. Полный audit сообщает о 19 moderate
в цепочке инструментов разработки; high/critical нет. Исправление этой цепочки требует
отдельного обновления инструментов с несовместимыми версиями и не применялось принудительно.
Backend выдаёт предупреждения об устаревающих API зависимостей, тесты проходят.
Автоматическая проверка доступности покрывает часть требований и не заменяет работу со скринридером.

Заключительный серверный прогон сначала прервался из-за заполнения диска ноутбука.
После удаления созданных нами временных тестовых каталогов он полностью повторён: 46 passed.
Пользовательские файлы и резервные копии не удалялись.
После очистки на диске C оставалось около 100 МБ; для дальнейшей загрузки фотографий
и нормальной работы ноутбука требуется освободить дополнительное место.
