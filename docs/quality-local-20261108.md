запоздалый успех и ошибка deep link, закрытие во время reload с выбором другого матча

## Публичный HTML

Добавлена команда `npm run refresh:prerender`: проверка типов, сборка отдельного
кандидата, обязательная проверка всех HTML без JavaScript, затем замена результата.
При неудачной сборке или проверке предыдущий результат сохраняется; параллельный
refresh пропускается. Сохранены предыдущий успешный артефакт и JSON состояния.
Режим `-- --watch` повторяет цикл через пять минут после завершения предыдущего.
Описание и примеры расписания: [deploy/prerender-refresh.md](../deploy/prerender-refresh.md).

При повторе на Windows после успешной проверки 50 HTML получен `EPERM` на
переименовании кандидата; откат восстановил предыдущий результат. Конкретный
держатель блокировки не установлен. Добавлены ограниченные повторы `EPERM`/`EBUSY`
при публикации, откате и восстановлении прерванной публикации: семь попыток с
суммарным ожиданием 7,85 с для каждого переименования. Постоянный отказ сохраняет
системный код и пути; если блокируется и откат, ошибка указывает местоположение
сохранённого предыдущего артефакта. Тесты реально выполняют переименования каталогов
с внедрёнными транзиентными и постоянными отказами: весь набор пререндера —
**17 passed**; targeted ESLint и Prettier проходят.

Следующий реальный запуск снова получил отказ при публикации и откате: прежний HTML
сохранился в `.data/prerender-refresh/previous`. После остановки нашего Vite он
восстановлен штатным `Move-Item` с проверкой путей и маркера артефакта. Служебная
`.data` исключена из Vite watcher вместе с `dist-prerender`; исходники приложения
не используют этот каталог. Vite перезапущен, и повтор полного refresh при
работающем сайте завершился успешно за 54,5 с: **50 страниц проверены и заменены**,
предыдущий артефакт сохранён, lock очищен. Причина конкретной Windows-блокировки
не устанавливалась; обход через исключение служебных каталогов подтверждён.

Финальный успешный цикл завершён `2026-11-08T08:23:30.640Z` (11:23 МСК),
`last_success=2026-11-08T08:23:21.183Z`, `routes=50`.
Лог: `.data/prerender-refresh-final-20261108.log`.
Сайт, админка, readiness API и календарь через proxy после завершения вернули 200.

Последний разовый цикл успешно проверил 50 страниц. Публичный домен ещё не выбран
владельцем, поэтому использован прежний тестовый origin `https://club.example`.
Это локальная проверка артефакта; постоянный процесс, серверный timer и внешний
deploy не включены. Перед публикацией требуется настоящий домен.
