# Бобрик — единый персонаж

Веб-экспорт двух предоставленных пользователем иллюстраций. Поза с мячом и поза
с поднятым большим пальцем собраны из одного лица, тела и формы. Исходный
тестовый Барс сохранён отдельно в `public/mascot/bars-up/` и
`docs/bobrik/reference-pet/bars-up/`.

`launcher.webp` — прозрачный статичный кадр 192 × 208. Он совпадает пиксель в
пиксель с декодированным первым кадром `idle` в `spritesheet.webp`, поэтому
переход к анимации при первой прокрутке не меняет размер, положение или цвет
персонажа.

Атлас 1536 × 1872 содержит 8 столбцов и 9 строк. Названия клипов и их число
кадров сохранены для совместимости с проигрывателем. Клипы `running-*` мягко
наклоняют и смещают всего персонажа при прокрутке; это не покадровая анимация
ходьбы. Надписи и номер 100 не отражаются зеркально. Вне прокрутки кнопка
возвращается к неподвижному первому кадру.

Экспорт воспроизводится с Pillow из прозрачных мастер-поз:

```powershell
python scripts/export_bobrik_assets.py --master docs/bobrik/art/bobrik-thumbsup.png --ball docs/bobrik/art/bobrik-ball.png
node scripts/verify-mascot-assets.mjs
```

Обе позы экспортируются с общими обрезкой, масштабом и положением, поэтому
лицо, корпус и ноги не смещаются при смене позы.

Скрипт сначала пробует lossless WebP и при необходимости уменьшает качество
RGB, сохраняя альфа-канал без потерь. Он проверяет отсутствие обрезанных краёв,
совпадение статичного кадра и лимиты 1 МиБ для атласа и 80 КиБ для кнопки.
Контрольные суммы исходных поз и файлов экспорта записаны в `animation.json`.
