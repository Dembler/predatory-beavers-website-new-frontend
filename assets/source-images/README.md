# Исходники изображений

Оригиналы фотографий, исходная эмблема и сохранённые эксперименты оформления перенесены из
`public/images`. Они остаются в репозитории, но не попадают в публичный deploy-артефакт Vite.
Рабочие URL опубликованных WebP и исторических фотографий сохранены.

`python scripts/optimize_images.py` воспроизводит актуальные фото и эмблему из этого каталога
в `public/images`, не изменяя исходники. PNG/WebP заставки и варианты композиции сохранены
для истории оформления; заставка в интерфейсе больше не используется.
