# Bars Up — временный локальный маскот

Исходники и описание происхождения: `docs/bobrik/reference-pet/bars-up/`.
Это снежный барс из переданного пакета, временный референс для Бобрика.

Web export: Pillow WebP quality=88, method=6, прозрачность сохранена.
Расположение кадров и исходные длительности сохранены. `animation.json`
содержит checksum экспортированного атласа; исходный атлас в docs не менялся.
`launcher.webp` — первый кадр, отдельно для лёгкой закрытой кнопки.

Проверка: `node scripts/verify-mascot-assets.mjs`.
